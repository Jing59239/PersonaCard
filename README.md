# PersonaCard

一个简单、轻量的 AI 角色卡生成器。

你可以填写角色的身份背景、性格、说话方式、对用户的称呼和开场白，并实时生成角色卡。

## 🌐 在线使用

https://jing59239.github.io/PersonaCard/

无需安装，打开网页即可使用。

## ✨ 功能

- 角色名称设置
- 身份背景设置
- 性格设定
- 说话方式设定
- 对用户称呼设置
- 开场白设置
- 实时角色卡预览
- 一键复制角色卡
- JSON 文件导出
- 浏览器本地自动保存
- 手机端适配

## 📷 界面

PersonaCard 使用简单的双栏布局：

- 左侧：编辑角色设定
- 右侧：实时预览角色卡

在手机上会自动切换为单栏布局。
